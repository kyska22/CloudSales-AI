# Perguntas Frequentes

## Quanto tempo leva para criar uma landing page?

Depende do conteúdo e da complexidade, mas normalmente uma landing page simples pode ser planejada e publicada em menos tempo do que um site completo.

## O cliente precisa ter domínio?

Não obrigatoriamente. O projeto pode começar sem domínio próprio, mas ter um domínio profissional passa mais credibilidade.

## O cliente precisa ter logo?

Não obrigatoriamente. Se o cliente não tiver logo, o projeto pode usar uma identidade visual simples com cores, tipografia e organização profissional.

## O cliente precisa enviar textos e fotos?

Sim, quanto mais material o cliente tiver, melhor. Mas o freelancer pode ajudar a organizar textos, estrutura e seções principais.

## O site pode ter botão para WhatsApp?

Sim. Esse é um dos recursos mais importantes para pequenos negócios, porque facilita o contato direto.

## Pode ter formulário?

Sim. O formulário pode ser usado para captar contatos, pedidos de orçamento, agendamentos ou dúvidas.

## Pode ter agendamento online?

Sim. Pode ser integrado com ferramentas de agendamento ou direcionar o cliente para WhatsApp.

## O projeto inclui hospedagem?

Depende da proposta. A hospedagem pode ser incluída, cobrada separadamente ou configurada em plataformas como Vercel.

## O projeto inclui manutenção?

Depende da proposta. É recomendado oferecer manutenção mensal como complemento.

## O site garante vendas?

Não. Nenhum site garante vendas sozinho. O site melhora apresentação, confiança e conversão, mas o resultado também depende de oferta, público, atendimento e divulgação.

## É possível começar simples e melhorar depois?

Sim. Essa é uma boa estratégia para clientes com orçamento menor. Primeiro cria-se uma versão essencial e depois evolui com novas funcionalidades.
